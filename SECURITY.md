# Security policy

## Supported versions

This project is pre-1.0. Security fixes are provided only for the latest commit
on the default branch until the first stable release policy is published.

## Reporting

Please use GitHub's **Report a vulnerability** / private security-advisory flow
for the repository. Include affected versions, impact, reproduction steps, and
a minimal synthetic proof. Do not include real credentials, tokens, recordings,
note contents, account identifiers, or private infrastructure details.

If private advisories are unavailable, open a content-free issue asking the
maintainer to establish a private channel. Do not post exploit details publicly
before a fix and coordinated disclosure date are agreed.

## Scope

Reports about the bridge source are welcome. Vulnerabilities in Light, Light
Cloud, OpenAI, ChatGPT, or third-party packages should also be reported to the
responsible upstream project through its published process.
